# 🏃 跑步路线规划助手

一个纯前端的跑步路线规划网页工具：输入位置和目标距离，自动生成 3 条沿真实路网的环形跑步路线，附带转向指引、热量估算、天气建议、分享海报等跑者专属功能。

**单文件实现，零构建，打开即用。**

## ✨ 核心功能

- 📍 **多种起点设置**：GPS 定位 / 地点搜索 / 坐标输入 / 地图点选（起点可拖动微调）
- 🔄 **环形路线 ×3**：按目标距离或时间自动闭环回起点，沿途每 200 米设标记点
- ↔️ **往返路线**：点选地图任意位置作为折返目标，自动生成往返路线
- 🛣️ **主干道优先**：按路段名称评分，自动避开小区内部巷道（需高德 Key）
- 🌙 **夜跑安全模式**：优先途经公园、广场等照明良好的地点
- 🧭 **转向指引**：逐条转弯提示（路段名 + 动作 + 累计里程）
- ⚖️ **路线对比视图**：三条路线的距离 / 耗时 / 配速 / 评分横向对比

## 🏅 跑者专属（区别于智能手表）

- ❝ 励志名言轮播（12 条，每 6 秒切换）
- 🌤️ 天气跑步建议（体感温度 / 湿度 / 风速三档判断）
- 🔥 热量估算（MET 公式，换算成"≈X 碗米饭"）
- 📸 分享海报（卫星地图背景、地址只显示到区县级保护隐私）
- 📝 路线点评（照明 / 路况 / 人流三维星级评分）
- 🏪 沿途补给点标注（便利店 / 公厕）
- 📅 跑步日志（打卡 + 累计里程 + 连续天数）
- 🎖️ 成就徽章墙
- 💾 导出 GPX 轨迹 / 收藏路线（均保存在浏览器本地）

## 🛠️ 技术栈

- **Leaflet 1.9.4**：地图渲染（OSM → 高德瓦片自动降级，含 GCJ-02 坐标转换）
- **高德开放平台**（可选）：步行路网规划、转向指引、公园选向、补给点搜索、卫星瓦片
- **OSRM / FOSSGIS**：无 Key 时的免费路网兜底
- **Open-Meteo**：实时天气（免 Key）
- **localStorage**：本地持久化（体重、收藏、日志、评分、Key）

## 🚀 使用方式

### 直接访问（推荐）

🌐 **https://crishehb.github.io/run-planner/**

HTTPS 环境，手机浏览器打开即可使用，「📍 获取我的定位」GPS 定位可直接授权。建议添加到手机主屏幕，像 App 一样使用。

### 本地运行

```bash
python -m http.server 8765
```

浏览器打开 `http://localhost:8765`。

> 注意：局域网手机访问时若为 HTTP 环境，浏览器会禁用 GPS 定位，需手动输入地点或点选地图。
